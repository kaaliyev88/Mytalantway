Tez-tez verilən suallar

Ən çox soruşulan sualların cavablarını burada tapa bilərsiniz.

Test neçə dəqiqə çəkir?
Standart test 10 sualdan ibarətdir və orta hesabla 8–12 dəqiqə çəkir. Vaxt limiti yoxdur — sualları rahat cavablayın.
Cavablarımı dəyişdirə bilərəmmi?
Hər suala yalnız bir dəfə cavab verilir. Cavabdan sonra növbəti suala keçilir və geri qayıtmaq olmur — bu, daha dürüst nəticə üçün nəzərdə tutulub.
Hansı ödəniş üsulları qəbul edilir?
Visa, Mastercard bank kartları, Birbank / ABB Pay və sayt daxili balans qəbul edilir. Bütün ödənişlər SSL şifrələməsi ilə qorunur.
Pulu geri almaq mümkündürmü?
Test başladılmamışsa tam geri qaytarma mümkündür. Test başladıqdan sonra ödəniş geri qaytarılmır. Texniki problem halında test yenidən aktivləşdirilir.
Nəticəm nə vaxt hazır olacaq?
Nəticə admin tərəfindən təyin edilmiş müddət (standart olaraq 24 saat) keçdikdən sonra hazır olur və şəxsi kabinetinizdə görünür. Nəticəyə baxmaq üçün kabinetinizə daxil olun.
Nəticəni başqası görə bilərmi?
Xeyr. Nəticələr yalnız sizin şəxsi kabinetinizdə görünür və ona yalnız siz daxil ola bilərsiniz. Admin paneldə yalnız ümumi statistika (şəxsi məlumat olmadan) görünür.
Şifrəmi unutmuşam, nə edim?
Giriş səhifəsindəki «Şifrəni unutdum» bağlantısına klikləyin. E-mail ünvanınıza sıfırlama linki göndəriləcək.
Hesabımı necə silə bilərəm?
info@mytalantway.az ünvanına «Hesab silinməsi» mövzusunda e-mail göndərin. Müraciətiniz 5 iş günü ərzində işlənəcək.
